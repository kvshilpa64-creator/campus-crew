Campus Crew

About the Project

Campus Crew is a campus-focused web application designed to help manage campus activities and provide useful features through a single platform.

Objectives

- Simplify campus-related activities.
- Provide an easy-to-use interface.
- Improve the management of campus operations.
- Provide useful simulation and recovery functionality.

Technologies Used

Frontend

- React.js
- TypeScript
- Tailwind CSS

Backend

- Node.js
- TypeScript

Development Tools

- Visual Studio Code
- Vite
- Git and GitHub

Installation and Setup

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

npm install --legacy-peer-deps

4. Start the development server:

npm run dev

5. Open your browser and visit:

http://localhost:3000

Project Structure

- "src/" – Frontend source code
- "server.ts" – Server entry point
- "package.json" – Project dependencies and scripts
- "vite.config.ts" – Vite configuration

Future Enhancements

- Better user experience and performance.
